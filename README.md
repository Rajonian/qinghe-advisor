# 青禾顾问工作台 v0.2

咨询成交与老客经营演示，保留原青绿色界面，升级为 Vinext + Cloudflare Worker + D1 服务端。

## 已实现

- 双向模拟会话，自定义客户消息、四种预设场景。
- 动态摘要、标签、回复草稿、下一步行动及版本化演示资料引用。
- 顾问预览并确认档案和任务调整；结束旧补货跟进、创建待确认回访。
- 按客户保存草稿，兼容旧版浏览器消息记录。
- AI与安全配置：保存Key、启停、连接测试、移除和脱敏调用记录。
- 未配置Key时为明确标注的规则演示；启用后服务端调用DeepSeek，不静默降级。

## 配置DeepSeek

在私有站点左侧点击「AI与安全配置」，在密码输入框填写Key，选择模型，勾选启用并保存，再测试连接。不要将Key写入源码、聊天记录或浏览器存储。

Key通过HTTPS发送至本站服务端，在D1中以AES-GCM密文保存，仅对当前登录账号生效。GET接口不返回明文或密文Key。加密主密钥CONFIG_ENCRYPTION_KEY由Sites环境secret提供；不要删除或轮换它，除非先安排已有Key重新配置。

## 本地开发

需要Node >=22.13。

```sh
npm run dev -- --port 4173
node --test tests/advisor.test.mjs
node node_modules/typescript/bin/tsc --noEmit
```

本地 `.dev.vars` 可配置独立的32字节base64加密主密钥，已被Git忽略。数据库需在首次构建后按starter支持的Wrangler D1命令应用 `drizzle/` 迁移；生产迁移由Sites发布流程应用。发布构建使用Sites技能共享build-site助手。
