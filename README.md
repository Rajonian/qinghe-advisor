# 青禾顾问工作台 Demo

静态 HTML / CSS / JavaScript，可交互演示咨询成交与老客经营。

## 本地运行

在本目录执行 `python3 -m http.server 4173 --directory dist`，打开 http://localhost:4173。

## 演示路线

今日工作 → 张女士补货跟进 → AI辅助回复 → 编辑与模拟发送 → 创建跟进任务 → 老客经营 → 完成任务及记录结果 → 我的业绩。

另支持客户搜索、切换、产品知识阅读、订单详情、售后跟进任务、客户备注、数据重置。

## 数据与能力边界

所有客户、价格、订单、基线指标均为演示样例。AI回复采用预设场景，不连接模型或真实服务渠道。操作保存在当前浏览器 localStorage。重置入口位于客户管理页面。
